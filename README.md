# Agenda-Web-Integrador
  Projeto acadêmico desenvolvido durante o curso técnico com o objetivo de praticar
programação em Java, organização em camadas (MVC) e integração com banco de dados.

------------------------------------------------------------------------------------

# Descrição
  Aplicação web simples de agenda de contatos web, permitindo cadastrar e visualizar
informações utilizando Java, JSP, CSS, JS e banco de dados MySQL.

  O projeto foi desenvolvido com fins educacionais, focando na lógica,
organização do código e boas práticas iniciais.

------------------------------------------------------------------------------------

# Tecnologias Utilizadas
  - Java
  - JSP
  - HTML
  - CSS
  - JavaScript
  - SQL
  - IDE Eclipse
  - MySQL Workbench

------------------------------------------------------------------------------------

# Conceitos Praticados
  - Programação Orientada a Objetos (POO)
  - Separação do projeto (Model, View, Control)
  - Acesso a Banco de Dados com JDBC
  - Estruturação de aplicação web em Java

------------------------------------------------------------------------------------

# Banco de Dados
  O script de criação do banco está localizado na pasta: Banco\Tabela_Agenda.sql
  
  O projeto utiliza MySQL como sistema de gerenciamento de banco de dados.
